===============
Beta features
===============

These are features or components that are being tested by the QICK community.
There may be bugs, documentation may be incomplete, and updates may break compatiblity with experiment code you write now.
Firmware components in beta are not included in the "standard" firmware bitstreams, but firmwares with these components may be available on request.

tProcessor v2
=============

Version 2 of the QICK tProcessor supports more output channels and allows more flexibility in writing QICK programs.
The assembly language, and therefore the Python API, for tProc v2 are incompatible with those for tProc v1.
